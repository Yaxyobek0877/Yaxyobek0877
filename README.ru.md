**Сайт:** [1pro.uz](http://1pro.uz/) &nbsp;·&nbsp; **Тип:** AI Inference Gateway &nbsp;·&nbsp; **Моя роль:** Backend и AI интеграция

**1Pro** — платформа, обеспечивающая **простой доступ к мощным AI-моделям через единый API**. Для стартапов и разработчиков: зарегистрируйтесь, начните с бесплатного тарифа и сразу запускайтесь через чат или API.

**Основная идея**
> Мы берём на себя сложность инфраструктуры —
> чтобы ваш стартап мог полностью сосредоточиться на создании AI-функций.

**Возможности**
- **Единый интерфейс** — один API-ключ, один формат endpoint. Быстрый доступ к моделям класса 70B.
- **Бесплатный старт** — бесплатная квота для новых пользователей. Точно отслеживайте расход токенов, лимиты и общее использование через дашборд.
- **Корпоративная безопасность** — строгие разрешения на уровне моделей. Ключи разработки, тестирования и production изолированы друг от друга.
- **OpenAI-совместимый API** — стандартный формат `chat/completions`, существующие SDK работают.

**Пример API** (поддерживается в Python, Node.js и cURL)

```python
import requests

api_key = "sk-[Ваш-Ключ]"
url = "https://1pro.uz/v1/chat/completions"

headers = {
    "Authorization": f"Bearer {api_key}",
    "Content-Type": "application/json"
}
data = {
    "model": "coder",
    "messages": [{"role": "user", "content": "Привет!"}]
}

response = requests.post(url, headers=headers, json=data)
print(response.json())
```

**Презентация:** [gazer.1pro.uz/presentation.html](https://gazer.1pro.uz/presentation.html) &nbsp;·&nbsp; **Тип:** Платформа распознавания лиц и умного кампуса &nbsp;·&nbsp; **Моя роль:** Backend / AI / тимлид

**Gazer Max** — **единая AI-платформа** для университетов, школ и организаций. Распознавание лиц, автоматический учёт посещаемости, управление турникетами и камерами, безопасность в реальном времени — всё в одной системе. **Протестировано на 20 000+ студентах** в Узбекистане.

**Слоган**
> Достаточно мельком показать лицо. Остальное сделает AI.

**Реальные показатели (университетское внедрение)**

| Показатель | Значение |
|---|---|
| Активная база студентов | **20 000+** |
| IP-камеры | **40+** |
| Турникеты | **30+** |
| Время поиска лица | **< 10 мс** |
| Точность распознавания | **99.6%** |
| Время внедрения | **1 неделя** |
| Открытие двери | **~50 мс** |

**Модули (12 шт., можно использовать независимо)**
- **Распознавание лиц (AI)** — 512-мерный эмбеддинг, индекс pgvector HNSW
- **Автоматический учёт посещаемости** — состояния `on_time` / `late` / `absent` / `left_early`
- **Монитор в реальном времени** — 40+ камер на одном экране, AI-анализ каждого кадра
- **Управление турникетами** — Hikvision (DS-K1T341CMF) через ISAPI, работает и оффлайн
- **Карта зданий и комнат** — иерархия Building / Floor / Classroom
- **Поиск по лицу** — загрузите одно изображение, получите полную историю (reverse search)
- **Синхронизация HEMIS** — студент/факультет/группа автоматически
- **Расписание занятий** — посещаемость рассчитывается автоматически по расписанию
- **Отчёты и аналитика** — live-дашборд, экспорт в Excel/PDF
- **Гранулярный контроль доступа** — точные камеры/здания/комнаты для каждого пользователя
- **Live аудит-журнал** — каждый вход, действие админа, попытка
- **Открытый REST API** — Swagger, scope API-ключей (read/write/full)

**Технический стек**
- **AI:** InsightFace (buffalo_l) + NVIDIA CUDA — лицевые эмбеддинги
- **Векторная БД:** PostgreSQL + индекс **pgvector HNSW**
- **Backend:** Django 5 + Celery + Redis
- **Frontend:** React 19
- **Медиа:** mediamtx (HLS и WebRTC, 25 fps)
- **Устройства:** Hikvision IP-камеры и турникеты (ISAPI)
- **Инфра:** Docker, **Cloudflare Tunnel** (только outbound — сервер не открывает ни одного порта)
- **Real-time:** WebSocket

**7-уровневая безопасность**
1. Cloudflare Edge (WAF, DDoS, бот, GeoIP)
2. Cloudflare Access (2FA для админ-панели)
3. nginx + TLS 1.3
4. Django + Argon2id (brute-force lock, CSRF, CSP)
5. База данных зашифрована (Fernet AES-256)
6. JWT (15-минутный токен) + API-ключи со scope
7. Полный аудит-журнал

**Пользователи**
Университеты · школы и лицеи · компании и офисы · медицинские учреждения · государственные органы · заводы и склады

**Результаты (через 1 месяц)**
- −92% времени учёта посещаемости (30 минут → 0)
- +45% точности учёта
- −68% инцидентов безопасности
- 0 сум на ID-карты

**Сайт:** [portal.1pro.uz](https://portal.1pro.uz/) &nbsp;·&nbsp; **Код:** [github.com/Yaxyobek0877/portal_traffic](https://github.com/Yaxyobek0877/portal_traffic) &nbsp;·&nbsp; **Моя роль:** Автор и главный разработчик

**Portal** — десктопное приложение, которое строит приватную **peer-to-peer mesh-сеть** между устройствами. Прямые соединения, сервера посередине нет (signaling-сервер участвует только в handshake). Локальная учётная запись, несколько комнат параллельно, автоматическое переподключение. Чат, файлы, port-туннелирование для камер/NVR/игровых серверов — всё P2P.

**Слоган**
> Сервера посередине нет. Прямые соединения.

**Основные возможности**
- **От 2 до 16 устройств** в mesh-сети — обмен по Portal ID + коду (роутер/VPN/проброс портов не нужны)
- **Чат и передача файлов** — drag-and-drop, end-to-end шифрование
- **TCP/UDP туннелирование** — обмен Minecraft-сервером, Hikvision NVR, LAN-камерами и другими сервисами через mesh
- **Живая mesh-диаграмма** — RTT, индикаторы NAT-traversal (LAN / Internet / TURN), bandwidth probe
- **QR + portal-код** — QR для того, кто рядом, ID + код для удалённого
- **Локальная учётная запись** — bcrypt пароль, без email и центральной регистрации
- **Мульти-portal** — семья + работа + игровые комнаты параллельно
- **Автоматическое переподключение** — предыдущие сессии восстанавливаются после перезагрузки
- **Per-service подтверждение** — каждое соединение подтверждается отдельно

**Шифрование: протокол PCP-1**
Второй уровень шифрования под WebRTC DTLS:
- **Ed25519** — identity-ключи
- **X25519** — обмен ephemeral-ключами
- **XChaCha20-Poly1305** — симметричное шифрование
- **Per-pair forward secrecy** — отдельные ключи для каждой пары

**Технический стек**
- **Сеть:** `pion/webrtc` (Go), full mesh, мультиплексируемый data channel, heartbeat
- **Десктопный UI:** Wails + React
- **Мобильное:** Android (бета, из исходников)
- **Хранилище:** SQLite (локальный vault)
- **Signaling:** стандартный endpoint `wss://signaling.1pro.uz/ws` (или свой)

**Платформы**
macOS (Apple Silicon и Intel) · Windows 10/11 (64-bit) · Linux (Ubuntu 22.04+) · Android (бета)

**Статус:** **v0.5.x живой релиз** · 8 этапов завершено · code signing в процессе · MIT лицензия · open source

```bash
# 1. клонируйте репозиторий
git clone https://github.com/Yaxyobek0877/portal_traffic.git
cd portal_traffic/client

# 2. создайте portal (терминал 1)
go run ./cmd/portal-cli -mode create -nick alice

# 3. подключитесь по коду (в другом терминале)
go run ./cmd/portal-cli -mode join -nick bob \
    -portal <ID> -code <КОД>
```
